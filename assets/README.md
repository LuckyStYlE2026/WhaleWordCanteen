# assets —— 美术素材放这里

这个文件夹里的**图片由你自己提供**。程序不联网下载任何素材,
仅自带了一份热门的deepseek形象


## 目录结构

```
assets/
├── ui/                  界面素材
│   ├── background.png   场景背景,会缩放到窗口大小
│   └── (其它图片)        放在这里的图会出现在「设置 → 底板图片」列表里
└── ai/                  虚拟教师的立绘,一个形象一个子文件夹
     └── default/
         ├── normal.png      平常
         ├── happy.png       答对时
         ├── sad.png         答错时
         └── ...

```

**程序只读 `ui/` 和 `ai/` 两个子目录。** 

## 立绘的命名规则

文件夹名 = 形象的「图片目录名」(在「AI 选择」页面里填的那个)。
文件名 = 情绪。认这六个:

| 文件名 | 什么时候会显示 |
|---|---|
| `normal.png` | 平时说话 |
| `happy.png` | 答对了 |
| `sad.png` | 答错了 |
| `thinking.png` | 答得模糊,老师在想 |
| `confused.png` | 答得离谱 |
| `surprised.png` | 意外情况 |

**只需要画你想画的那些。** 少的那几张会自动退回到 `normal.png`,
所以只画一张正面立绘也能正常玩 —— 那样至少还有个人站在那儿,
而不是一个灰框。一张都没有时才是占位框。

## 尺寸与格式

**这两条尺寸要求是"文字糊不糊"的分水岭,不是审美建议。** 立绘在 1280×720
的窗口里要占到大约 335×503 像素,背景要铺满 1280×720 —— 素材比这还小的话,
程序只能把它放大,而放大出来的画面必然发虚

| 素材 | 建议尺寸 | 说明 |
|---|---|---|
| 立绘 | 高 900~1200 像素,**带透明通道** | 窗口高度决定它多大;画幅高一点永远比宽一点安全 |
| 背景 | 1920×1080 或更大,**16:9** | 比例不合时上下(或左右)会留出底色条 |
| 底板图 | 随意,会等比缩放居中 | 见下面「界面底板」 |

- 一律 `.png`,**立绘必须带透明通道(alpha)**,否则立绘会带一整块背景色。
  这是最容易踩的一条:一张 JPEG 光是改名成 `.png` 并不会长出透明通道,
  它在深色场景上会显示成一个**白框**。
- **背景请用 16:9。** 程序是"等比缩放后居中"贴背景的,一张比 16:9 更扁的
  图会上下留白,留白处填的是主题底色 —— 看起来就是背景上多了一条横线。
  宽高比不确定时,宁可给一张更大的图。

## 界面底板(主界面左侧那块、学习页的单词框那块)

底板是画在场景图上的**一个图层**,位置在**背景图之上、所有界面控件之下**。
所以它能半透明、也能换成你的图片。两件事都在
「设置 → 界面底板与立绘」里调:

- **底板图片**:列表是**扫 `assets/ui/` 目录生成的** —— 往文件夹里丢一张图,
  重进设置页就能选它。默认是「默认(一层主题色)」= 不选任何图片,
  这时底板铺的是**主题背景色**(深色主题下一块深蓝灰的板)。
- **底板透明度**:0.50 ~ 1.00。1.00 是完全不透明;越小越透,越能看见背景。
  下限是 0.50 而不是 0:**底板上的文字是真实的界面控件,颜色是固定的**
  —— 再透下去底色会滑到"深色字和浅色字都不够清楚"的那一段,读起来费劲。
- **对话框透明度**:老师说话那一块。它的文字是画在图片里的、永远清晰,
  所以这一项可以拉到很透(0.30~1.00),不影响阅读。

> **底板颜色变了,界面上的字色会跟着变。** 你选一张亮色的图当底板时,
> 正文和次要文字会自动换成深色那一套(判据是对比度),词卡也会换成
> "深卡片 + 浅字"。所以**亮的图、暗的图都能用**,不需要你另外调配色。

改完点「保存设置」立刻生效。值存在 `save/settings.json` 的 `ui` 段里
(`panel_image` / `panel_opacity` / `dialog_opacity` / `character_scale` /
`character_anchor_x` / `character_anchor_y`)。存的是**比例**而不是像素,
所以换个分辨率构图不会跑掉。

## 点老师可以聊天

点画面上那位老师,会进入对话页:老师移到窗口中间,其它界面收起来。
**输入框只在配好 API 之后才能用** —— 没配的时候它是灰的,并写明原因。
鼠标移到老师身上会变成小手,那就是"这里能点"的提示。

## 换背景

往 `assets/ui/` 里丢一个 `background.png` 就行。程序也会认 `bg.png`
和 `background.jpg` —— 不想让你为了一个文件名别扭。
