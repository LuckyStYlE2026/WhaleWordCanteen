# 运行「鲸鱼单词食堂 WhaleWordCanteen」需要的第三方库。
#
# 安装:  pip install -r requirements.txt
#
# 只有两个。这不是省事,是这个软件的定位 —— 单机、离线、双击就能跑,
# 依赖越多,打开它的人遇到"装不上"的概率就越高。

# 图像:立绘、背景、对话框的合成与缩放。全程离线使用,不联网。
# 锁在 10.4.0 是因为这是最后一个支持 Python 3.8 的版本,
# 而当前开发环境就是 3.8.6(见下方说明)。
Pillow==10.4.0

# 只有你在「设置 → 配置 API」里填了 base_url / model / key 之后,
# 这个库才会被真正用到。不配置 API 的用法完全不需要它 ——
# 但装在环境里不会带来任何网络行为。
requests>=2.24.0

# --------------------------------------------------------------------------
# 没有列在这里,但同样是必需的:
#
#   tkinter   图形界面。它是 Python 标准库的一部分,Windows 官方安装包
#             默认就带,不需要 pip。Linux 上如果报 "No module named _tkinter",
#             用 apt install python3-tk / dnf install python3-tkinter 补上。
#             它是这个项目选 Tkinter 的主要原因之一:考试模式的答案要用
#             中文输入法输入,而只有真实的控件才能唤起输入法。
#
#   其余全部是标准库:json / csv / difflib / unicodedata / uuid / pathlib /
#   random / math / importlib …… 一概不用装。
#
# --------------------------------------------------------------------------
# 关于 Python 版本
#
# 开发与验证都在 Python 3.8.6 上完成。这个版本已经停止维护(2024-10 EOL),
# 因此代码里刻意避开了 3.9+ 的语法(不用 list[str]、不用 X | None、不用 match),
# 为的是在更老的机器上也能跑起来。
#
# 更高版本(3.9 ~ 3.13)同样可以使用,只需把上面 Pillow 的版本限制去掉 ——
# 那个 == 是为了兼容 3.8 才写死的。
