# 鲸鱼单词食堂 WhaleWordCanteen

一个**单机、离线**的背单词桌面软件。Galgame 风格的 AI 虚拟教师坐在屏幕右下角,
陪你一个词一个词地背;复习时间由记忆曲线安排;词库完全是你自己的。

> **这个软件不联网。** 全部数据都存在你自己电脑上,不请求任何服务器、
不上传任何内容、不需要注册账号。唯一的例外是你在「设置」里主动填了 API 密钥 ——
那是可选功能,不填就一切照常,只是"老师"话少一点。

## 它有什么

| 板块 | 做什么 |
|---|---|
| **开始** | 今天该复习哪些词、还剩几个新词;勾选词包去学习或考试 |
| **单词设置** | 导入自己的词表、手动建词、改释义、导出;支持 CSV / JSON / 旧式行格式 |
| **记忆曲线** | 按艾宾浩斯间隔(1/2/4/7/15/30 天)安排复习;画出遗忘曲线与未来 30 天的任务量 |
| **AI 选择** | 换虚拟教师的形象与人设;立绘用你自己准备的图片 |
| **设置** | 分辨率、全屏、主题、判分方式、API |

### AI 是怎么设计的

「离线负责简单判断,复杂的、情绪化的都交给大模型」是贯穿整个设计的一条线:

- **平时说话不花一分钱。** 虚拟教师的日常台词来自本地台词库,
  每个「判分结果 × 情绪」组合都存了好几条变体轮流用,不会复读。
  立绘表情也由本地规则决定(答对→开心,答错→难过),不问模型。
  这一层扛掉了大约 90% 的对话。
- **判分默认离线。** 纯字符串比对,零成本。它**刻意不尝试理解语义** ——
  拿不准就老实说"模糊",绝不为猜得准一点去调模型。
- **只有三种情况才会真的调用 API**:① 判分落在"说不清对不对"的模糊地带;
  ② 你主动问老师;③ 一次学习/考试结束后生成一句总评。
- **有上限。** 设置里可以限定"单场最多调几次 API"(默认 20)。超了自动退回纯离线,
  并在界面上告诉你。宁可少说话,也不能悄悄烧钱。

不配 API 的话,以上这些你都不会察觉 —— 软件功能完整,只是那个"老师"只会说台词库里的话。

## 跑起来

需要 Python 3.8 或更高(开发环境是 3.8.6)。

```bash
cd game
pip install -r requirements.txt
python main.py
```

**第一次打开时界面是空的,这是正常的** —— 先去「单词设置」导入
`wordlists/CET4-example.csv`,或者把你自己的词表拖进去。文件格式见
[wordlists/README.md](wordlists/README.md)。

想换掉默认形象和背景,把图片放进 [assets/](assets/README.md)。

## 自己做插件

内置的每一个可替换部件都挂在同一套注册表上:**判分器、复习调度算法、
词表导入/导出格式、AI 后端、台词包、界面板块**。

仓库里带了一个真能跑的示例插件 `plugins/example_export/` ——
它给"导出"加了一种 Markdown 格式。把它复制一份改名,就是你的插件骨架。


## 代码怎么组织的

```
game/
├── main.py          入口。就四行流程:注册内置 → 加载插件 → 注册界面 → 开窗口
├── core/            纯逻辑。判分、调度、导入导出、统计都在这里
├── ui/              界面。只有这一层认识 Tkinter
├── plugins/         插件
├── tests/           单元测试
├── assets/          美术素材(你自己放)
├── wordlists/       词表
└── save/            运行数据,不进版本库
```
