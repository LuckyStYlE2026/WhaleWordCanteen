# wordlists —— 词表放这里

「单词设置 → 导入词表」和「导出」默认都指向这个文件夹。名字用英文而不是
「单词表」,是因为中文目录名在少数 Windows 环境的命令行、打包工具和压缩软件里
会出现编码不一致,表现成"文件明明在,程序却说找不到" —— 这个问题很难排查,
而避免它只需要一开始就取英文名。界面上显示给用户的名字仍然是中文。

导入时不需要你选格式,程序自动识别。

## `.txt` —— 带花括号的一行一词

一行一个词,字段名用中文,**引号里的逗号不算字段分隔符**:

```
{单词: "atmosphere",发音: "/ˈætməsfɪə/", 翻译: "n. 大气层,大气圈; 气氛", 组合:"1"}
```

这一条最值得注意的地方是 `"n. 大气层,大气圈; 气氛"` —— 释义里那个逗号
如果被当成字段分隔符,整行就错位了。所以字段值要用引号包起来。

## `.txt` 之外:最朴素的一行

也认不带花括号的写法,每行「单词 + 分隔 + 翻译」。分隔优先用**制表符**
(从 Excel 复制出来就是它),没有制表符时按空白切一刀,剩下的全归翻译:

```
atmosphere	n. 大气层,大气圈; 气氛
lithosphere	n. 岩石圈
```

## `CET4-example.csv` —— 逗号分隔

用 Excel 打开、编辑、另存为 CSV 就行。表头认中文:

```
单词,发音,翻译,例句,搭配,组合
ocean,/ˈəʊʃn/,"n. 海洋,大洋",,,
```

**翻译里可以带逗号**,用双引号包起来即可

## 关于「组合」

`组合`(group)每个样例里都有,**它是可选的**。填了以后,学习模式下同组的
单词会一起出现在同一页 —— 适合按课文、按 Unit 背。留空就是"未分组"。


## 导入时的几条行为

- **格式自动识别**,不用选。程序按 json → 旧式行 → csv → 纯文本的顺序试,
  认不出来时按最朴素的「单词 翻译」硬读,并告诉你第几行有问题。
- **重复导入不会丢进度。** 判断依据是单词拼写(NFKC 归一化 + 忽略大小写),
  已经背过的词再导入一次只会更新释义文字,复习进度原样保留。
  所以"导入了发现少两个词,补上再导一次"是完全可以放心的操作。
- **一次导入会报告**读到了多少词、哪几行有问题。某一行读失败不会中断整次导入 ——
  导 500 个词时不该因为第 7 行有问题就给你一片空白。

## 导出

导出时可以在几种格式里挑一种,或者选「全部格式」。除了内置的 CSV / JSON,
插件注册的导出格式也会出现在这个列表里 —— 比如仓库自带的
`plugins/example_export/` 会让这里多出一个「Markdown」。

- **CSV**:给 Excel 改词用。带 BOM,中文版 Excel 打开不会乱码。
- **JSON**:带 id 和完整学习状态,是真正无损的那一份,重新导入进度不丢。
